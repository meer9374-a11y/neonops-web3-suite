Playbook #01: Solana & Base RPC Automation Cheat Sheet (2026 Edition)

Use native fetch in Node.js v20+ to interact directly with public EVM & Solana RPC nodes without heavy SDK bloat.

1. Verified Public Mainnet Endpoints (Zero API Key)

  • Base Mainnet: https://mainnet.base.org (Native USDC: 0x833589fCD6eDb6E08f4c7C32D4f71b54bdA02913)
  • Arbitrum One: https://arb1.arbitrum.io/rpc (Native USDC: 0xaf88d065e77c8cC2239327C5EDb3A432268e5831)
  • Polygon PoS: https://polygon-bor-rpc.publicnode.com (Native USDC: 0x3c499c542cEF5E3811e1192ce70d8cC03d5c3359)
  • Solana Mainnet: https://api.mainnet-beta.solana.com (USDC Mint: EPjFWdd5AufqSSqeM2qN1xzybapC8G4wEGGkZwyTDt1v)

2. Query ERC-20 USDC Balance via Raw eth_call

// balanceOf(address) selector = 0x70a08231 + 32-byte padded address
const selector = '0x70a08231' + address.toLowerCase().slice(2).padStart(64, '0');
const res = await fetch('https://mainnet.base.org', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    jsonrpc: '2.0', id: 1, method: 'eth_call',
    params: [{ to: '0x833589fCD6eDb6E08f4c7C32D4f71b54bdA02913', data: selector }, 'latest']
  })
});
const { result } = await res.json();
const usdc = Number(BigInt(result)) / 1e6;

3. Query Solana SPL USDC Balance via getTokenAccountsByOwner

const res = await fetch('https://api.mainnet-beta.solana.com', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    jsonrpc: '2.0', id: 1, method: 'getTokenAccountsByOwner',
    params: [
      solAddress,
      { mint: 'EPjFWdd5AufqSSqeM2qN1xzybapC8G4wEGGkZwyTDt1v' },
      { encoding: 'jsonParsed' }
    ]
  })
});

4. Security Checklist Before Handling Real Funds

  • Never commit mnemonics, .env, or private keys to Git. Enforce .gitignore before git init.
  • Separate hot public display configs (public_addresses.json) from cold offline key vaults.
  • Always test exchange deposits with a small amount first and verify matching network (Base vs Arbitrum vs Solana).
